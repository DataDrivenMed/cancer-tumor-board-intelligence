# NCCN AI-use restriction

The repository must not ingest, transform, summarize, embed, index, or otherwise process NCCN guideline content unless the operator has separate written authorization from NCCN that expressly permits use with artificial-intelligence models/tools for the intended deployment.

Institutional access to NCCN content alone is not treated as sufficient authorization for AI processing.

If a supplied NCCN document contains language prohibiting use with artificial intelligence models or tools, the licensed-guideline adapter must reject it. Do not copy NCCN guideline text into this public repository.

Until explicit AI-use authorization is documented, use other authorized guideline/consensus sources for machine processing, such as the open-access European LeukemiaNet AML recommendations, while preserving source attribution, versioning, and the existing evidence-verification gates.

This policy is a software safety and licensing control, not legal advice.
